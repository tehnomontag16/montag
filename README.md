# Сайт ТехноМонтаж

Остекление, обшивка, утепление и ремонт крыш балконов.
Набережные Челны, Нижнекамск, Елабуга. Телефон +7 (937) 572-45-62.

Сайт: https://tehno-montag.ru

## Что где лежит

- `index.html` — главная страница целиком: вёрстка, стили и скрипты в одном файле
- `privacy.html` — политика обработки персональных данных
- `images/` — фотографии работ: `balkony/`, `kryshi/`, `naruznye/`

## Как добавить фотографию

1. Положите файл в нужную папку внутри `images/`
2. В `index.html` найдите «ГАЛЕРЕЯ РАБОТ — СПИСОК ФОТОГРАФИЙ» и допишите строку:
   `{ cat:"balkony", file:"balkony/17.jpg", caption:"Что сделали, материалы, город" },`

Фото лучше горизонтальные или вертикальные до 1600 пикселей по длинной стороне и до 500 КБ.

## Публикация

Сайт публикуется на Netlify из ветки `main`. Команда сборки не нужна,
каталог публикации — корень репозитория. После отправки изменений
сайт обновляется автоматически за минуту.
